## 📌 Tentang Saya
Selamat datang di ruang kerja digital saya! Nama saya **Reza**, atau lebih dikenal dengan panggilan **Zenns**. Saya saat ini sedang menempuh pendidikan di **Universitas Dinamika Bangsa Jambi**. Saya sangat suka merancang solusi inovatif, mulai dari aplikasi web hingga ekosistem desentralisasi.

- ⚡ **Bekerja** sebagai Software Engineer dan Fullstack Developer.
- 🔗 **Fokus** sebagai Smart Contract Specialist dengan ketertarikan mendalam pada teknologi Web3 dan blockchain.
- 🎮 **Kreator** **StackBlockArcade**, sebuah game berbasis blockchain yang mengintegrasikan *smart contract*.
- 🌱 **Selalu belajar** dan mengeksplorasi teknologi baru untuk membangun sistem yang lebih baik.
